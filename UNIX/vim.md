## 1. `~/.vimrc`: 自动将 Vim Yank 内容同步到 macOS 剪贴板

在 `~/.vimrc` 添加这个配置：

```vim
augroup copy_to_macos
    autocmd!
    autocmd TextYankPost * if v:event.operator ==# 'y'
        \ | call system('pbcopy', getreg('"'))
        \ | endif
augroup END
```

每次执行 `yank` 操作时，将 Vim 的 *unnamed register* 内容通过 `pbcopy` 同步到 macOS 系统剪贴板。

### 1.1. 命令解释

| 配置                       | 作用                                                     |
| -------------------------- | -------------------------------------------------------- |
| `TextYankPost`             | 文本进入 register 后触发                                 |
| `v:event.operator ==# 'y'` | 只处理 `yank`，避免 `dd`、`cw`、`x` 等操作覆盖系统剪贴板 |
| `getreg('"')`              | 获取 Vim 的 *unnamed register*                             |
| `pbcopy`                   | 写入 macOS 系统剪贴板                                    |

### 1.2. 为什么需要判断 `y`

`TextYankPost` 不仅会在 `yank` 时触发，删除、修改等操作也可能更新 register。

因此如果直接写：

```vim
autocmd TextYankPost * call system('pbcopy', getreg('"'))
```

执行 `dd`、`dw`、`cw` 等操作时，也可能把内容同步到 macOS 剪贴板。

通过：

```vim
v:event.operator ==# 'y'
```

可以确保**只有 `yank` 操作才同步剪贴板**。

### 1.3. 为什么不使用 `unnamedplus`

另一种方式是：

```vim
set clipboard=unnamedplus
```

它会让 Vim 的 *unnamed register* 与系统剪贴板关联。

这里使用 `TextYankPost + pbcopy` 的好处是：

> **Vim 的 register 和 macOS 系统剪贴板保持相对独立，只在 Yank 时额外复制一份到系统剪贴板。**

因此不会改变 Vim 原本的 `yy`、`p` 等 register / paste 行为。

## 2. `f`、`F`、`t`、`T` 字符查找与跳转

这 4 个命令都是**在当前行内查找字符并移动光标**。

| 命令      | 作用         | 方向 | 光标停在哪里               |
| --------- | ------------ | ---- | -------------------------- |
| `f{char}` | 向后查找字符 | →    | 停在目标字符上             |
| `F{char}` | 向前查找字符 | ←    | 停在目标字符上             |
| `t{char}` | 向后查找字符 | →    | 停在目标字符**前一个字符** |
| `T{char}` | 向前查找字符 | ←    | 停在目标字符**后一个字符** |

### 2.1. 找到后继续跳转

| 命令 | 作用                                                 |
| ---- | ---------------------------------------------------- |
| `;`  | 重复上一次 `f` / `F` / `t` / `T`，**同方向**继续查找 |
| `,`  | 重复上一次查找，**反方向**查找                       |

### 2.2. 一个很实用的记忆表

| 命令 | 含义                            |
| ---- | ------------------------------- |
| `f`  | **Forward**，向后找，停在目标上 |
| `F`  | 向前找，停在目标上              |
| `t`  | **To**，向后找，停在目标前      |
| `T`  | 向前找，停在目标后              |
| `;`  | 重复查找，同方向                |
| `,`  | 重复查找，反方向                |

## 3. 调整当前行在屏幕中的位置

| 命令 | 作用               | 说明                                                                 |
| ---- | ------------------ | -------------------------------------------------------------------- |
| `zz` | 当前行居中         | 将**光标所在行**滚动到屏幕垂直方向的中间位置，光标所在的文本位置不变 |
| `zt` | 当前行移到屏幕顶部 | 将**光标所在行**滚动到屏幕顶部，通常会留出一定的顶部空间             |
| `zb` | 当前行移到屏幕底部 | 将**光标所在行**滚动到屏幕底部，通常会留出一定的底部空间             |

### 3.1. 记忆方式

可以把 `z` 理解成：

> **调整屏幕，让当前行出现在指定位置。**

后面的字母表示目标位置：

| 命令 | 记忆                                |
| ---- | ----------------------------------- |
| `zz` | **z + z** → 当前行放中间            |
| `zt` | **z + t** → `t` = **top** → 顶部    |
| `zb` | **z + b** → `b` = **bottom** → 底部 |

**注意：**这三个命令都是调整**屏幕滚动位置**，不会改变光标所在的文本行，也不会改变光标在该行中的列位置。

## 4. `aw`、`iw` 文本对象

| 命令 | 全称            | 作用               | 包含内容              |
| ---- | --------------- | ------------------ | --------------------- |
| `aw` | **around word** | 选择一个完整的单词 | 单词本身 + 周围的空白 |
| `iw` | **inner word**  | 选择一个单词内部   | 仅单词本身            |

### 4.1. `aw` vs `iw`

| 特性                   | `aw`     | `iw`     |
| ---------------------- | -------- | -------- |
| 当前光标需要在单词开头 | ❌ 不需要 | ❌ 不需要 |
| 选择整个单词           | ✅        | ✅        |
| 包含周围空白           | ✅        | ❌        |
| 常用于删除             | `daw`    | `diw`    |
| 常用于修改             | `caw`    | `ciw`    |
| 常用于复制             | `yaw`    | `yiw`    |

### 4.2. 记忆方式

| 符号 | 含义                                       |
| ---- | ------------------------------------------ |
| `a`  | **around**，围绕整个对象，通常包含周围空白 |
| `i`  | **inner**，对象内部，不包含周围空白        |
| `w`  | **word**，单词                             |

所以可以记成：

```text
aw = around word
iw = inner word
```
